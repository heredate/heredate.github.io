# Hereda+ · web publicada

Carpeta `web/`: la web de Hereda+ tal como se publica (página de presentación, aplicación en `app/`, cuestionario de la familia en `familia/`, calculadora en `calculadora/` y páginas legales). Se genera con `build.py` desde el código fuente, que no está en este repositorio.

Cada cambio en `main` se publica automáticamente en GitHub Pages (acción «Publicar Hereda+»). La aplicación guarda los datos en el navegador de cada equipo; no hay servidor ni base de datos.
